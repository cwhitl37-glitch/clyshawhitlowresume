CLYSHA WHITLOW - LIVE PORTFOLIO
How to publish on Netlify
--------------------------------------------------

WHAT IS IN THIS FOLDER

  index.html                     The entire site in one file. Works offline.
  assets/Clysha-Whitlow-Resume.pdf   The resume the "Download resume" button opens.
  README.txt                     This file.

Keep the folder structure exactly as it is. The resume button looks for the
PDF at assets/Clysha-Whitlow-Resume.pdf.


PUBLISH IT (about two minutes)

  1. Go to app.netlify.com and sign in.
  2. Click "Add new site", then "Deploy manually".
  3. Drag this whole folder onto the drop area. Do not drag index.html by
     itself, or the resume download will break.
  4. Netlify gives you a URL like random-name-12345.netlify.app.
  5. Site configuration > Change site name to set something cleaner, for
     example clyshawhitlow.netlify.app.


USE YOUR OWN DOMAIN (optional)

  Buy the domain, then in Netlify: Domain management > Add a domain.
  Netlify walks you through the DNS records. HTTPS is automatic and free.


UPDATING THE SITE LATER

  Ask for a fresh export, then drag the new folder onto the same site
  under Deploys. The URL stays the same.


BEFORE YOU PRINT BUSINESS CARDS

  The QR code on the cards has to point at the URL you settle on above.
  Send that URL over and the card files get regenerated to match.
